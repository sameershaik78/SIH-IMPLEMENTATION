System Controls & Settings

Perform continuous risk audit updates and manage machine learning pipelines.

Trigger Risk Recalculation

Force the Risk Engine to run recalculations across all assets, active vulnerabilities, threat likelihoods, and active controls. This will recalculate all Single Loss Expectancies (SLE), Annualized Loss Expectancies (ALE), and trigger active security alerts.

Continuous Monitoring: This is usually performed automatically in the background when assets or CVEs change.
Train Random Forest Model

Retrain the Machine Learning classifier using historical security incidents, asset attributes, and threat logs. This updates the ml/model.pkl and compiles new evaluation metrics (Accuracy, Precision, Recall, F1) to show on the dashboard.

This action will overwrite the existing model parameters. Only accessible by Admins.
